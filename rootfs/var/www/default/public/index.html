Это демо-страница эталонной конфигурации nginx / OpenResty / Angie со сквозной трассировкой запросов.

ID запроса к этой странице: …

Что проверить

  • Заголовки ответа: curl -I http://localhost/ — X-Request-ID и заголовки безопасности. X-HOP-Name и X-Request-Chain по умолчанию видны только клиентам с loopback-адреса (внутренняя топология).
  • Проксирование в бэкенд: curl http://localhost/api/demo — бэкенд покажет, какие заголовки трассировки он получил, включая цепочку X-Request-Chain.
  • Свой trace ID: curl -I -H "X-Request-ID: 0123456789abcdef0123456789abcdef" http://localhost/
  • JSON-лог: docker compose logs -f gateway

Замените содержимое rootfs/var/www/default/public/ своим сайтом, а бэкенд — в sites-available/default/upstream.conf.
